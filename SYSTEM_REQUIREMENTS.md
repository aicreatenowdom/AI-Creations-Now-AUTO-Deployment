# System Requirements and Operating Scope

The official AUTO Deployment product page is the current source of truth for supported Windows editions, prerequisites, licensing, and installation terms.

General requirements include:

- A supported Windows Server edition with Desktop Experience or a supported Windows 11 Pro system
- Local administrator authority
- Internet connectivity for activation, managed delivery, verification, and configured online services
- Current, tested, recoverable system backups
- A dedicated administrator-managed environment suitable for the configuration changes disclosed by the product

Windows 11 Home and other editions not listed on the official product page are not supported by Production 4.7.

Review https://aicreatenow.com/autodeploy.html before purchase or installation.

## Product overview

AUTO Deployment Production 4.7 is commercial Windows operations software for supported Windows servers and Windows 11 Pro systems. It combines guided deployment, continuous monitoring, critical event intelligence, local evidence, scheduled briefings, operational audits, reporting, and controlled Remote Desktop actions.

The public product page describes approximately **50–75 distinct alert and status-notification types**, together with nightly executive, networking/bandwidth, storage, and audit briefings.

## Master Command Center

The local Windows console brings together:

- 15 labeled read-only operational audits
- Gold, delivery-verification, and complete system reports
- On-demand executive, storage, and network briefings
- Controlled Remote Desktop lockdown and temporary unlock actions
- Protection-chain, service, system-health, attack, resource, IIS, and administrator-use visibility

## Continuous operational intelligence

Representative monitored conditions include:

- Successful and suspicious Windows access
- Firewall attacks and attacker blocking
- RDP exposure, lockdown, and restoration
- Critical services and system health
- Disk and directory storage conditions
- Reliability events and restart conditions
- Network and bandwidth anomalies
- Website/IIS availability where configured
- Scheduled-task health and reporting delivery

This repository is a public product-information and documentation hub. It does not contain the commercial executable, private deployment source, licensing implementation, infrastructure credentials, customer configurations, or proprietary security automation.

## Important operating scope

AUTO Deployment is intended for administrator-managed systems. Installation can make material Windows configuration changes described in the official product terms, including changes involving firewall, Remote Desktop, services, power, updates, Microsoft Defender, and account/UAC policy. Customers should maintain current, recoverable backups and review all published requirements before purchase and installation.

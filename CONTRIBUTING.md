# Contributing to the AUTO Deployment Repository

This repository documents proprietary AUTO Deployment software. The application source code, installation package, licensing implementation, and private security automation are not published, and public source-code contributions are not accepted.

Useful public contributions include documentation corrections, broken-link reports, reproducible non-sensitive product defects, and supported-Windows compatibility observations. Remove credentials, server identifiers, public IP addresses, customer data, license information, and security-sensitive logs before posting.
